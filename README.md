# Shaggy - Tutorial datasets

This branch holds the datasets read by the [tutorials](https://shaggy.readthedocs.io/en/latest/tutorials.html) of the documentation.

- `data/x-dummy.pt` and `data/m-dummy.pt`: ocean columns of temperature and oxygen, and their land mask (optimizers tutorial).
- `data/m.pt`: land mask of the Black Sea state (autoencoder tutorial), whose states `data/x.pt` (671 MB) are too large for git.
