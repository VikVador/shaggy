Tutorials
=========

Tutorials and test notebooks live on the `master-demo <https://github.com/VikVador/shaggy/tree/master-demo>`_ branch, a copy of `master` that also holds the datasets they use.

* `demo-optimizers.ipynb <https://github.com/VikVador/shaggy/blob/master-demo/notebook/demo-optimizers.ipynb>`_ compares the available optimizers (SOAP, HybridMA with Muon) against AdamW.
* `demo.ipynb <https://github.com/VikVador/shaggy/blob/master-demo/notebook/demo.ipynb>`_ trains an asymmetric 3D :class:`~shaggy.models.ConvAE` on real ocean data, encoder then decoder, and compares its reconstruction error to the dataset mean.
